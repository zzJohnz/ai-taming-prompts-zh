# 🧠 AI 中文调教指南

> 各种场景使用指南，学习怎么驯服大模型。

## 这是什么？

这是一个精心整理的中文提示词（Prompt）集合，帮你更好地和 AI 对话——不管是 ChatGPT、DeepSeek、豆包、Claude 还是 Kimi。

你直接复制下面的提示词发给 AI，它就能扮演对应的角色帮你干活。

## 分类

| 分类 | 数量 | 说明 |
|:---|:---:|:---|
| 💼 工作写作 | 27 条 | PRD、项目经理、金融分析、求职信、标题生成器、论文优化 |
| 💻 技术开发 | 35 条 | SQL终端、DBA、全栈开发、正则生成器、IT架构师 |
| 🌐 翻译润色 | 11 条 | 英翻中、词典、去重工具、Midjourney联想器 |
| 🏠 生活辅助 | 38 条 | 旅游、厨师、营养师、医生、心理咨询 |
| 🎮 娱乐休闲 | 15 条 | 冒险游戏、足球解说、塔罗、诗人、小说家 |

## 怎么用？

1. 找到你需要的角色
2. 复制对应的提示词
3. 粘贴发给 AI
4. 把方括号 `[在这里输入...]` 里的内容换成你自己的需求

## 数据格式

所有提示词都在 `prompts-zh.json` 里，格式：

```json
{
  "act": "角色名称",
  "cat": "分类",
  "prompt": "提示词正文"
}
```
